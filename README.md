## Sobre mim

Estou em transição para a área de **QA**, com foco principal em **testes de API**, **Postman**, **aplicações web** e **análise de qualidade**.

Gosto da parte de investigar comportamento, validar cenários, encontrar falhas e organizar isso de forma clara. A ideia deste GitHub é reunir projetos e estudos que mostrem essa evolução de forma prática.

## Foco atual

- Testes de API
- Métodos HTTP
- Postman
- Aplicações web
- DevTools
- Casos de teste e bug reports
- Noções de HTML e CSS
- Noções de PostgreSQL e MongoDB
- QA voltado para IA
- Engenharia de prompt
